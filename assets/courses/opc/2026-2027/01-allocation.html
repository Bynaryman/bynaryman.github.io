Dynamic memory allocation on the heap

We open an image and discover its dimensions. Where do we store its pixels?

  1. Make an independent copy.
  2. Store values and find memory errors.
  3. Organise arrays, strings and matrices.
  4. Group data with user-defined types.

SLIDES

When does the storage end?

The pointer and the object it refers to have separate lifetimes.

Storage Lifetime ends
Ordinary local array When its block ends
Block from malloc When it is released with free
Global or static object When the program ends

Each recursive call has its own locals. Too many calls can exhaust the stack.

SLIDES

Context: Static storage is reserved before execution. Ordinary locals last for their block execution; recursive calls have separate locals. A pointer’s scope does not prove that its target is alive. Allocated storage persists until release even if a pointer is overwritten.

The free contract
