# Asset provenance

- `background.webp`: unchanged from Louis Ledoux's
  `mlir_summer_school/assets/images/background.webp`. The web theme applies a
  subtle, uninverted parallax texture over a white background.
- `filters/slide-layout.lua`: heading/body separation adapted from that project.
- `styles/lecture.scss`: original white theme implementation with dark blue,
  green and red accents. The earlier dark variant is retained only in Git history.
- `rennes-logo.svg`: official mark obtained from the
  [University of Rennes brand site](https://charte.univ-rennes.fr/ressources/logos),
  specifically `https://charte.univ-rennes.fr/themes/custom/ur1_external_mdb/logo.svg`.
  The PDF is a vector conversion; both formats display the black mark.
  The mark's proportions and lettering are unchanged.
- `diagrams/*.svg` and matching PDF: TikZ drawings from `cours/figures/*.tex`,
  built by `scripts/diagrams.py`, following the examples and pointer states in CM7.
- `cm7-quiz.pdf`: unchanged copy of the inherited
  `CM/Print_for_students/kahoot/CM8-C-language-kahoot-to print.pdf`. Despite its
  filename, its internal title is CM7 Dynamic Memory Allocation. The similarly
  named CM7 file contains a different quiz and is not used here.
- Teaching sequence and original examples: A. Kritikakou, CM7, pages 1–74.
  Original PDF and PowerPoint remain in `CM/`. English adaptation and technical
  corrections are documented in `cours/SOURCE-MAP.md`.
