# SeaMOS layout reader

Run `./scripts/strata-parser/build.sh` with Git and Zig 0.15.2 on the path to rebuild the static browser reader. It fetches pinned revisions of Tiny Tapeout Explorer (miniz, qhull declaration stub and WASI shim) and its gdstk submodule. The app serves the checked-in WebAssembly and JavaScript locally.

The worker-side `readLayout(buffer, cellName)` creates a fresh WASI instance with the input in memory. gdstk reads GDSII and OASIS, including compressed OASIS blocks, and converts paths to outlines. The wrapper lists top and child cells before expanding geometry. It walks the selected cell, applies affine placements and array offsets, and emits polygon rings grouped by numeric layer and datatype. Each polygon retains its direct hierarchy branch and nearest recognized standard-cell type. The built-in logic table uses exact cell names from the [SKY130 HD Liberty library](https://github.com/The-OpenROAD-Project/OpenROAD-flow-scripts/tree/master/flow/platforms/sky130hd/lib) and the [IHP SG13G2 standard-cell library](https://github.com/IHP-GmbH/IHP-Open-PDK/tree/main/ihp-sg13g2/libs.ref/sg13g2_stdcell/lib). Coordinates and curve tolerance (0.001 µm) are in micrometres. Text and layout properties are outside the polygon model.

The parser accepts files up to 64 MiB and runs in a 256 MiB WASM heap. Large expanded designs switch automatically to shared cell meshes with instance transforms. Preview draws upper faces at whole-chip zoom and full walls up close. Ray tracing uses the full solids, a BVH per cell mesh, and a second BVH for placements. Unique geometry and placement buffers still have browser memory budgets.
