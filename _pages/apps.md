## Getting started

1. Connect your MIDI interface’s **OUT to the rack’s IN**, and the rack’s **OUT to the interface’s IN**. On the TR-Rack, enable System Exclusive and match its Global MIDI channel.
2. Open the editor, choose **Connect TR-Rack**, allow MIDI/SysEx access, select both ports and identify the instrument. The browser must support Web MIDI with SysEx; the app reports when it is unavailable.
3. Select a program on the rack and press **Receive**. Turn on **Live edit** to send and verify the temporary buffer. Effects and program-name edits are applied with **Send to buffer**, or by enabling Live edit again.
4. Listen through your interface’s direct monitor, or connect the rack’s stereo audio outputs to two line inputs and use **Enable audio**. Browser “microphone” permission also covers line inputs. Choose that stereo input pair and your listening output.

### Keyboard & release

With **Computer keys on**, the labeled keys on the on-screen piano play notes. Hold several keys for a chord; each key-up releases its own note. The **QWERTY / AZERTY** selector changes the displayed key labels to match your layout.

<div class="app-keyboard-guide" markdown="1">

| Control                                      | Action                                                                  |
| -------------------------------------------- | ----------------------------------------------------------------------- |
| A W S E D F… (QWERTY), Q Z S E D F… (AZERTY) | Play the labeled chromatic notes                                        |
| Space                                        | Hold the sustain pedal; release Space to lift it                        |
| Sustain button                               | Latch or release sustain                                                |
| Z / X (QWERTY), W / X (AZERTY)               | Shift the playing octave                                                |
| Esc or Panic                                 | Stop all notes                                                          |
| Pointer / touch                              | Hold notes, play chords with multiple touches, or slide between keys    |
| Envelope square handles                      | Drag left/right to change stage time; arrow keys also work when focused |

</div>

Choose **Polyphonic** in the playing controls for chords and send the change to the rack. A monophonic program still plays one voice. If the program’s **Hold** parameter is on, turn it off to hear normal note-off release tails. The release sound itself is generated by the rack; the app does not emulate its PCM engine. The optional test tone checks keyboard input only.

### Scope & privacy

This public beta targets **TR-Rack PCM programs**. It does not yet edit Combinations, Multi setups, drum-kit keys or PCG files, and it is not a software version of the Trinity sound engine. Only the TR-Rack device identity has been tested. Keep a backup of your own programs before permanent writes.

Programs stay in the browser or in files you export. MIDI and audio access require browser permission. The editor does not upload your presets or record your audio, and the public build contains no captured hardware banks. Browser storage is specific to this site and browser; export a library file to move it between computers or from the localhost version.
